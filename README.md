# Set Builder

A browser-based environment modeling app for game blockouts (Kotlin + Spring Boot server, React + WebGPU web app).

## Requirements

- JDK 21 (`brew install --cask temurin@21`, or `brew install openjdk@21` and `export JAVA_HOME=/opt/homebrew/opt/openjdk@21`)
- Node 26 and npm

## Run the server

`cd server && ./gradlew bootRun` (port 8080)
