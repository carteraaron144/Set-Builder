# M0 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A browser app that opens an empty, flat scene in a WebGPU viewport with a Cities: Skylines-style camera, saves and reloads it locally (IndexedDB and a downloadable project file), and is served by a Kotlin Spring Boot server that also serves asset packs.

**Architecture:** Monorepo with `web/` (React + TypeScript + Vite, Three.js WebGPURenderer through react-three-fiber, Zustand editor state) and `server/` (Kotlin + Spring Boot, Gradle Kotlin DSL). The browser owns all editing, rendering and saving; in v1 the server only serves the built web app (`/`), a health check (`/api/health`) and asset packs (`/api/asset-packs`, `/packs/**`). Camera math, the scene model and the file format are pure TypeScript modules with unit tests; React components are thin.

**Tech Stack:** JDK 21, Kotlin 2.x, Spring Boot 3.5.x (the current Initializr default), Gradle wrapper; Node 26, React 19, Vite, TypeScript (strict), three (r180+, `three/webgpu`), @react-three/fiber 9, zustand, idb, fflate, zod, Vitest, @testing-library/react, fake-indexeddb.

**Spec:** Design doc "Environment Modeler — Design Doc", https://claude.ai/code/artifact/6c15080f-9693-489e-89ed-54e596c066b9. Relevant sections: Core experience and controls, Rendering, Technical architecture, Data model, persistence and export, Milestones (M0).

## Global Constraints

- v1 generation and rendering run in the browser only; the server never generates.
- Saves are local only: browser storage (IndexedDB) plus download/upload of one project file (a .zip of JSON + layer blobs). No accounts in v1.
- Scene sizes are 64, 128 or 256 m square, chosen at creation; 256 × 256 m is the maximum. No streaming.
- Units are metres, Y-up. Terrain in M0 is a flat plane at y = 0 centred on the origin.
- Target 60 fps at 1080p on integrated laptop GPUs.
- Art style: stylised low-poly, flat or simply shaded.
- Camera bindings (from the design doc): Pan = middle-drag, screen-edge scroll, WASD / arrows · Orbit = right-drag, Q / E · Zoom = wheel toward the cursor, R / F · Tilt = right-drag vertical, Page Up / Page Down. (First-person mode on G is M1+, not M0.)
- TypeScript `strict: true`; Kotlin package root `app.setbuilder`. App name in UI copy: "Set Builder".

## Review Focus

1. **No WebGPU** (Firefox, older Safari): the app must fall back to WebGL2 and show a small "WebGL2 fallback" badge, never a blank canvas; with neither, show a clear "needs WebGPU or WebGL2" message. Test in Task 7.
2. **Bad project file uploaded** (not a zip, missing `scene.json`, invalid JSON, wrong shape, newer `formatVersion`): show an error naming the problem and leave the current scene untouched. Tests in Tasks 3 and 8.
3. **IndexedDB unavailable** (private windows, blocked storage) or a failed write: Save shows an error and Download still works. Tests in Tasks 4 and 8.
4. **Unsaved changes lost**: New, Open and Upload ask before replacing a dirty scene, and closing the tab triggers `beforeunload` while dirty. Test in Task 8.
5. **Camera keys while typing** in the scene-name field must not move the camera, and keys held when the window loses focus must not stay "stuck". Test in Task 6.

  export interface GroundPoint { x: number; z: number }
  export interface CameraState { target: GroundPoint; yaw: number; pitch: number; distance: number } // radians, metres
  export interface CameraLimits { half: number; minDistance: number; maxDistance: number; minPitch: number; maxPitch: number }
  export function cameraLimits(sceneSize: SceneSize): CameraLimits;
      // half = size/2, minDistance 5, maxDistance 2*size, minPitch 15°, maxPitch 85°
  export function defaultCameraState(sceneSize: SceneSize): CameraState;
      // target {0,0}, yaw 45°, pitch 50°, distance 0.9*size
  export function pan(s: CameraState, right: number, forward: number, l: CameraLimits): CameraState;
      // metres along the camera's ground-projected right/forward axes; target clamped to ±half
  export function orbit(s: CameraState, dYaw: number): CameraState;          // yaw wrapped to [0, 2π)
  export function tilt(s: CameraState, dPitch: number, l: CameraLimits): CameraState;
  export function zoom(s: CameraState, factor: number, l: CameraLimits, toward?: GroundPoint): CameraState;
      // distance *= factor (clamped); if toward is given, target moves toward it by (1 - clampedFactor) of the gap,
      // so the ground point under the cursor stays under it
  export function cameraPosition(s: CameraState): { x: number; y: number; z: number };
      // target + spherical offset: y = distance*sin(pitch); horizontal = distance*cos(pitch) along yaw
